# Topic Taxonomy for Dashboard Reports

## Overview

The Topic Taxonomy organizes all advisor reports into 7 major business domains. Each topic contains related reports and maps to specific advisor categories.

---

## Topic Map

### 1. 📊 Business Analytics (İş Analitikleri)

**Emoji:** 📊  
**Icon Color:** Blue (#4A90E2)  
**Priority:** High

#### Description
Business analytics reports focus on quantitative analysis, performance metrics, trend evaluation, and data-driven insights for strategic decision-making.

#### Included Categories
- `sector` — Industry and competitive intelligence
- `operasyon` — Operations and daily management
- `iş-analizi` — Business process analysis
- `veri` — Data analysis and metrics

#### Associated Advisors
1. **Sektör & Rakip İstihbarat** (Sector Intelligence)
   - Competitive analysis
   - Industry benchmarks
   - Market trends
   - Threat assessment

2. **İş Analizi Danışmanı** (Business Analysis)
   - Process optimization
   - Efficiency metrics
   - Workflow improvement
   - Resource allocation

3. **Veri Analisti** (Data Analyst)
   - KPI tracking
   - Data visualization
   - Statistical analysis
   - Trend forecasting

4. **Operasyon Müdürü** (Operations Director)
   - Daily briefing
   - Performance dashboard
   - Resource status
   - Operational metrics

#### Report Types
- Monthly performance reviews
- Quarterly business reviews
- Market analysis reports
- Operational dashboards
- Efficiency assessments
- Competitive positioning
- Budget vs. actual analysis
- KPI reports

#### Typical Report Metrics
- Revenue/cost data
- Market share
- Operational efficiency
- Process metrics
- Performance indicators
- Trend analysis
- Forecasts

## Topic Selection Algorithm

When organizing reports, the system applies this priority:

1. **Primary Category** — Use advisor's main category if it maps to a topic
2. **Secondary Mapping** — Check alt-categories if primary doesn't exist
3. **Fallback** — Use "Business Analytics" as default
4. **Multi-Category** — Some advisors map to multiple topics (list in both)
