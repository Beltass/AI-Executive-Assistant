# agents/

Her ajanın implementasyonu (sistem promptu referansı, araç/tool
tanımları, testler) burada kendi alt klasöründe yaşayacak, ör.:

```
agents/
├── orchestrator/
├── email-agent/
├── calendar-agent/
├── memory-agent/
├── job-search-agent/
└── cv-optimizer/
```

Ajan görev tanımları için bkz. `../docs/AGENTS.md`. Faz 1 kapsamı
(hangi ajanların önce geleceği) için bkz. `../docs/ROADMAP.md`. Bu
klasör Faz 1 geliştirmesi başladığında doldurulacaktır.
