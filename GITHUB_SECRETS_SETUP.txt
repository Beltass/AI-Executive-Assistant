================================================================================
LOCAL SETUP BEFORE GITHUB SECRETS
================================================================================

For a smoother deployment, complete these steps locally first:

1. Google OAuth Setup:
   python -m ai_assistant.integrations.google_oauth_setup
   → Creates .google_token.json with refresh_token
   → Copy refresh_token to GOOGLE_REFRESH_TOKEN secret

2. Slack Channel Setup:
   python -m ai_assistant.integrations.slack_setup --apply --write-env
   → Creates all channels and saves IDs to .env
   → Copy all SLACK_CHANNEL_* values to GitHub secrets

3. Verify Health:
   python -m ai_assistant.health
   → Confirms all integrations are ready

4. Test Daily Digest:
   python -m ai_assistant.daily_digest
   → Full end-to-end test before deploying to CI

================================================================================
TROUBLESHOOTING
================================================================================

"missing env var(s): GEMINI_API_KEY or OPENAI_API_KEY"
→ Add at least one LLM secret

"Slack: SKIPPED — missing env var(s): SLACK_BOT_TOKEN"
→ Add SLACK_BOT_TOKEN from your Slack app OAuth settings

"No Google credentials/token configured"
→ Add all three Google secrets (CLIENT_ID, CLIENT_SECRET, REFRESH_TOKEN)

"Unauthorized" or "Invalid token"
→ Verify token is current (some services rotate tokens)
→ Check token has correct scopes/permissions
→ Try regenerating the token fresh

"timeout or connection refused"
→ GitHub Actions network access OK - check service status
→ Verify API endpoint URLs are correct and reachable
→ Check rate limits on the service (Gemini free tier, Slack workspace limits)

================================================================================

✓ Never commit secrets to the repository

✓ Secrets are NOT printed in workflow logs (GitHub masks them)
